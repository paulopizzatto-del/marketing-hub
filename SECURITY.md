# Segurança e privacidade

Este projeto é um conjunto de prompts, arquivos de skill e scripts locais. Não salva perfis de marca remotamente nem se conecta automaticamente a redes sociais.

- Não inclua passwords, cookies, tokens, dados pessoais, contratos ou fotos privadas em issues, exemplos ou commits.
- Leia os scripts antes de executar código de terceiros.
- O instalador cópia arquivos localmente; não usa rede nem solicita credenciais.
- Se identificar uma vulnerabilidade, prefira o recurso privado de reporte de vulnerabilidades do GitHub, se ativado pelo mantenedor. Não divulgue detalhes exploraveis em issue pública.
- Perfis de marca reais devem ficar no seu ambiente privado, nunca em exemplos do repositório.
