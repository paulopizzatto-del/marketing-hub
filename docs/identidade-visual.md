# Identidade visual

Nome: Marketing Hub. Assinatura: “Seu marketing, num lugar só.” Escopo do produto: conteúdo e social media.

Cores fornecidas: Rosa Hub `#FF4F8B`, tinta `#2B1720`, branco `#FFFFFF`, fundo `#FFF7FA`. Tipografia indicada: Poppins, quando disponível; este pacote não distribui fontes.

Usar as logos e o ícone fornecidos, preservando proporções, cores e respiro. Artes criadas com apoio de IA sob direção do responsável e preservadas byte a byte. Consulte [procedência](../assets/ASSET-PROVENANCE.md).

O banner e a prévia social anteriores foram retirados da vitrine e ficam em [arquivo histórico](../assets/archive/v2.3.0/README.md). Para novas peças, usar “skill + prompt portátil”, “cartão de voz” e “revisão de conteúdo”; evitar declarações de compatibilidade pronta ou resultados não medidos. A nova arte precisa ser enviada e aprovada pelo responsável.

Se o GitHub estiver usando a prévia antiga nas configurações de Social preview, removê-la manualmente. A alteração de arquivos não modifica automaticamente aquela configuração.

## Apresentação do projeto no GitHub

- **README: uma única imagem no topo.** Preferir `assets/brand/marketinghub-horizontal-fundo-rosa.png`, com fundo sólido, para manter legibilidade em claro/escuro. Não exibir várias logos lado a lado.
- **Sem galeria entre instalação e documentação.** A prancha `previa-marca.png` é referência de marca e não demonstra uma funcionalidade.
- **Sem duplicação no rodapé.** O texto de autoria, licença e proveniência deve ter links, não outra imagem grande.
- **Sem reestilizar os assets originais.** Preservar o hash dos arquivos e o respiro.
- **Social preview é separado do README:** revisar manualmente em Settings antes de divulgar.
- **Material candidato não é release oficial:** não apontar links para páginas não ativadas ou anunciar como disponível.
