# Procedência dos elementos visuais

**Regra deste projeto:** usar exclusivamente as imagens que o responsável enviou. Nenhuma imagem foi criada, refeita, colorizada ou editada na preparação desta versão.

Os arquivos foram copiados byte a byte dos pacotes `MARKETING-HUB-GITHUB-KIT.zip` e `MARKETING-HUB-LOGO_1.zip`. A verificação usa SHA-256. As cópias repetidas nos diretórios da skill, plugin e site são intencionais.
